# Palm Hill Link PDF store (branch `link-pdf-store`)

Storage-only branch. Never merge into `main`; Vercel never deploys it (`vercel.json`).

Each Palm Hill Link PDF lives here and is served with `Content-Type: application/pdf` through
`https://cdn.jsdelivr.net/gh/zeoszeos/palmhillnews@<commit>/<file>`, pinned to the commit that added it.
`https://palmhillnews.vercel.app/pages/archive/link/<file>` redirects there (main `vercel.json`, generated by
`scripts/link_redirects.py` from `data/link-issues.json`). The same files are also release assets on
https://github.com/zeoszeos/palmhillnews/releases/tag/link-pdfs (fallback + permanent copy).

New months are added by `scripts/fetch_link_pdf.py` on the Friday build. Never delete or rewrite a file here (STYLE-RULES R15/R29).
