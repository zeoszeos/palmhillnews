Hurricane Season Begins in One Week

📅 Tuesday, May 26, 2026
If you would like to respond to this notification, please place your response above the dotted line. Some important reminders for everyone before hurricane season begins Monday 6/1/2026. If there is an evacuation order issued Palm Hill will be included when they call for Zone A. Please have a plan in place now so that you are ready should that occur. If you have special needs you will need to register ahead of time. If there is an evacuation order the county will assist in getting you to a hurricane shelter. A link for the information regarding this: https://pinellas.gov/special-needs/ If there is an evacuation order you can find information on shelters here: https://pinellas.gov/emergency-information/public-shelters/ This list will show if the shelter has been opened and what type of shelter it is. You can find a list of items that you should have to be prepared for an emergency here: https://pinellas.gov/make-a-plan/build-your-emergency-kit/ Also, attached is the current Hurricane Plan which has information on the storms and other information not contained in this email. Please always remember that things are replaceable, people are not and make safe decisions for yourself!
