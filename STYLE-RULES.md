# PHNEWS Style Rules (locked format)

These are Steven Leonowicz's locked format decisions for the Palm Hill Newsletter (PHNEWS) and its pages on palmhillnews.vercel.app.
**Don't change them without Steven's OK.** The golden screenshots for this look are in `tests/golden/format-locked-2026-10-18/`, and git tag `format-locked-2026-10-18` marks the repo at that point.

Where each rule is enforced:
- Shared code: `scripts/style_rules.py`, imported by the issue builder, live preview, publish step and recurring generator.
- Archive hub generator: `scripts/build_archive.js`.
- Video hub generator: `scripts/build_meeting_video_archive.py`.
- Checks: `scripts/check_title_months.py` and `scripts/visual_regression.py`, which run on every builder pass.
- Deploy size: `scripts/check_deploy_size.js` runs at the end of every Vercel build (R29).

## Workflow: batch merges (Steven, Oct 17 2026)

Every PR makes a Vercel preview deployment and every merge makes a production deployment, and each one counts against the 10 GB Deployment Storage limit (R29). So **batch changes**: collect a session's approved fixes on one branch and open **one PR per batch** (normally one per work session or per weekly build), not one PR per small fix. Merge only when Steven approves the batch. Urgent single fixes (a wrong date or time going to residents) can still go alone.

## Readability rules RD1–RD13 (Steven, Oct 17 2026, 3:44 AM — approved READABILITY-RULES-PROPOSAL)

Every reading page on palmhillnews.vercel.app is set for an over-55 audience. **These rules change layout only; the source wording is never changed.**
- Shared style: `pages/assets/ph-read.css`. It is linked by `scripts/readability.py`, which also tags `<body class="ph-rd ph-rd-<template>">`.
- Templates: `early` (webmaster/calendar shell), `message` (President's Message / Community Stories), `card` (Chair Reports, Manager Updates, Shareholders, event cards), `info`, `shell` (notice source copies, event/Zoom/meeting pages), `table` (Recurring), `simple`.
- Generators call `readability.apply()`: `event_page.py`, `meeting_zoom_page.py`, `recurring_grouped.py`, `publish_oct18.py`. Chair Listen pages are rebuilt by build_archive.js from the item page, so they inherit it.
- Pages from the legacy webmaster pipeline (outside this repo) are covered by running `python3 scripts/readability.py` after any import; it is idempotent.
- Guard: `/workspace/.venv-vr/bin/python scripts/check_readability.py` (every page in scope, rendered at 1280px and 390px; exit 1 on any failure).
